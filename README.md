# CampusConnect — College Information Portal

A responsive, beginner-friendly multi-page college portal built with HTML, CSS, and vanilla JavaScript.

## Pages
- Home
- About
- Events & Activities
- Study Resources
- Campus Updates
- Student Corner
- Contact

## Working features
- Responsive navigation menu
- Event category filtering (Technical, Cultural, Sports)
- Event registration confirmation saved in browser LocalStorage
- Searchable study resource cards
- Smart campus search sample (events/resources/updates)
- Contact and suggestion form validation
- Suggestion storage in LocalStorage

## Run locally
1. Extract `CampusConnect.zip`.
2. Open `index.html` in a browser.
3. For best testing, use VS Code + Live Server.

No npm installation or build step is required.

## Important limitations
This is a frontend demonstration. LocalStorage is local to the current browser and does not share data with other users or devices. Contact form submission only displays a demo success message; it does not send email. Event/announcement content is sample data and is not official college information.
